    Revocation notice

    If your key is ever lost or stolen, a revocation notice tells people to stop trusting seals made with it. Make one now and keep it with your backup: if you lose your key, you won’t be able to make one any more.

        About SEAL

        For five thousand years, people in Mesopotamia signed clay with cylinder seals: small carved stones rolled across wet clay, leaving a picture only their seal could make. SEAL does the same for digital files, with modern cryptography instead of carved stone.

        How it works

        1. Your seal is an Ed25519 key pair made by your browser. The private key stays on this device, locked so that it can sign but can’t be copied. The public key is shared inside every seal.
        2. Your Seal ID is a short fingerprint of your public key, like SEAL-7K3M-Q9XA-2PDF-W4HN. Your emblem is drawn from the same fingerprint.
        3. Sealing computes a SHA-256 fingerprint of the file and signs it, together with the file name, size, your declared date and your note.
        4. Verifying checks the signature with the public key in the seal, then recomputes the file’s fingerprint. If a single byte changed, it won’t match.

        Where the seal goes

        • PNG images can carry the seal inside the file (in a metadata chunk). The image itself is not changed.
        • Plain text and Markdown can be “clear-sealed”: the seal is added at the end between -----BEGIN SEAL----- and -----END SEAL----- lines. Line endings may change (Windows or Mac style) without breaking the seal; any other edit breaks it.
        • Any other file gets a small separate .seal file. Share both together; the file itself is untouched.

        Privacy

        SEAL is a static web page. It has no server, no accounts, no analytics and no third-party code. It never uploads your files: they are read and processed in your browser. The page’s security policy forbids it from contacting any other website.

        What’s stored on this device: your seal’s locked private key and public key, the names you save for known seals, and any revocation notices you choose to remember. Clearing this site’s data in your browser deletes them.

        Keeping your seal safe

        • Keep your backup file and passphrase. Browsers can clear site data — Safari does this after 7 days without a visit, unless SEAL is added to the home screen.
        • Anyone who can run code on this page while it’s open could use your key without copying it. Only use SEAL from a copy you trust, and keep your browser up to date.
        • Make a revocation notice now and keep it with your backup, in case your key is ever stolen.

        Formats and source

        The seal formats are open and documented, so anyone can build a verifier. See docs/FORMAT.md and the README in SEAL’s source code repository.
